Orthophotos

An aerial photo is not a map: its scale changes with the terrain, and everything that rises above the ground leans outward. An orthophoto removes these effects, so the image can be measured like a map while still showing every detail of the photo.

From central projection to orthogonal projection

Chapter 1 showed why a photo is not a map: a central projection puts higher points further from the centre, and its scale varies with the flying height above each spot. A map is an orthogonal projection: every point is dropped vertically onto the reference surface. To turn one into the other we need to know, for each point on the ground, where it appears in the photo. The collinearity equations answer that, as soon as we know three things: the photo's interior and exterior orientation, and the terrain height at the point.

Indirect rectification

The orthophoto is built backwards, from the output to the input:

  1. Lay a grid of output pixels over the ground, for example every 2 m.
  2. For each pixel centre (X, Y), read the height Z from the terrain model.
  3. Project (X, Y, Z) into the photo with the collinearity equations and the interior orientation; the result is a position between scan pixels.
  4. Take the grey value at that position by resampling, and write it to the output pixel.

Working backwards guarantees that every output pixel gets exactly one value, with no gaps and no overlaps.

Resampling

The projected position rarely falls on a pixel centre, so the grey value has to be interpolated from the neighbours.

Mosaics and seamlines

An orthophoto of a larger area is assembled from several photos. Where photos overlap, each output pixel can take its value from any of them. A simple and good rule is to use the photo whose nadir is nearest, because relief displacement and occlusion are smallest near the nadir. The borders between the parts, the seamlines, then run midway between neighbouring exposure stations. Production systems move seamlines along roads or field edges, and adjust brightness so the joins disappear.

How good is an orthophoto?

The orthophoto is only as accurate as the terrain model under it. A height error Δh at a point that lies a distance R from the nadir on the ground shifts it horizontally by about

Δs≈RH·Δh

At the edge of the sample photos, R/H is about 0.7, so a 10 m height error moves a point by 7 m. Buildings and trees are usually not in the terrain model at all, so their roofs and crowns still lean outward in an ordinary orthophoto. A true orthophoto, which also corrects those, needs a surface model that includes the objects and a way to fill the areas they hide.
